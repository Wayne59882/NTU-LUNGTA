## 之後如何讓編輯狀態清楚

每次以一個可說明的改動提交，例如「修正測驗跳題後的選項保留」或「補充教材檢索失敗時的回覆」。在 PR 中記錄觸發情境、改後行為及實際驗證。GitHub 將隨真實提交更新檔案的最後修改訊息與日期；無須為了畫面拆造過去的開發歷程。
