# v241.12.5 完整版 R12：帳號、老師／學生權限與 Email 審核（2026-10-30）

以 R11（單題問答修正、語音、老師版 V/Q、原本的上傳課程介面）為底，加上帳號與權限。

## 使用方式

1. 進入網站一律先到登入頁。沒有帳號的人按「申請帳號」，填姓名、Email、密碼、申請身分（學生／老師）與身分說明（學號、系所或任教課程）。
2. 申請送出後，系統寄「帳號申請待審核」信到管理員信箱（與答案回報同一個信箱，預設 admin@example.com）。信中的「審核頁面」可選「核准為學生」、「核准為老師」或「不核准」。連結 30 天內有效、只能使用一次。
3. 核准後對方即可登入。內建呼吸生理課程也需要登入才能使用。

## 兩種介面

| | 學生 | 老師 |
|---|---|---|
| Lecture、AI 助理問答、Scenario Practice、V/Q 視覺模型 | ✓ | ✓ |
| 上傳 PDF、建立／刪除課程、重新準備題目 | ✗（介面隱藏，伺服器也拒絕） | ✓ |
| 看得到的上傳課程 | 輸入課程代碼加入的課程 | 只有自己上傳的課程 |

- 每門上傳課程有 6 碼「課程代碼」，顯示在老師的課程選單下方。老師把代碼給學生，學生在「我的課程」輸入代碼即可使用。
- 老師之間看不到彼此的教材；即使知道課程編號，伺服器也會拒絕（課程內容、問答、測驗、刪除都檢查）。
- R12 之前建立的課程歸管理員帳號所有。

## 管理員

- 管理員＝與答案回報同一個 Email（VQ_AUTH_ADMIN_EMAIL 可另外指定）。第一次使用時，先用這個 Email 申請「老師」，再到信箱核准自己。
- 登入後右上角「帳號審核」：核准、改身分、停用、重設密碼（產生臨時密碼）。
- 伺服器上也可以用：`python3 auth_admin.py list | approve EMAIL student|teacher | reject EMAIL | disable EMAIL | reset-password EMAIL | courses | test-email`

## 寄信限制

沿用答案回報的寄信設定（feedback/feedback.env，Resend 或 SMTP）。若寄件者仍是 Resend 測試寄件者（onboarding@resend.dev），只能寄給管理員自己，所以系統不會另外寄信通知申請人；核准後請自行告知對方可以登入（審核頁面會提醒）。在 Resend 驗證自己的網域並設定 VQ_RESEND_FROM 後，申請人也會收到核准通知。

## 技術說明

- 帳號存在 auth/auth.sqlite3（密碼以 PBKDF2-SHA256 雜湊；登入憑證是 30 天的 HttpOnly、Secure、SameSite=Lax cookie）。
- 權限在 gateway.py（公開網址的入口）檢查：所有 /api/ 都需要已核准的登入；上傳／建立／刪除課程限老師；任何帶 course_id 的請求都檢查課程擁有者或課程代碼。
- Cloudflare Worker 在送出 /、/reference/、/kb/ 頁面前先確認登入，未登入轉到 /login/。
- 回答的提示詞、檢索、模型與課程資料都沒有改。
