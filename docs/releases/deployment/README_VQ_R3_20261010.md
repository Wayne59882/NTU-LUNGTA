# R3正式版本說明

此ZIP保留原完整v241.12.5应用程式。正常No V/Q mismatch的11項初始輸入，以及前一完整計算版的所有正常輸出不變。正式病理示範設定：Low V/Q f=28/min（明列呼吸代償），Diffusion DLO2=6 mL/min/mmHg，True shunt=0.50（50%真正分流）。正常設定不使用這些病理輸入。

實際計算：Low V/Q end-capillary PCO2=47.11；High V/Q arterial PCO2=56.31；Diffusion PAO2=99.11、PaO2=69.92 mmHg。True shunt在FiO2 0.21→0.40時PaO2=43.15→48.74；同通氣、血流、代謝與Hb的無分流對照=87.72→225.65 mmHg。真正分流的血液不接觸肺泡氣體；動脈血依分流血液與有通氣區血液的氧含量混合後反解。小幅PaO2變化保留，不把輸出硬改為零。

正式資料在內層VQ_CALCULATION_REPORT：teacher_cases_R3_20261010.json、ui_checks_R3_20261010.json、normal_baseline_R3_20261010.json、verified_cases.json，以及VQ_TRUE_SHUNT_COMPARE_20261010.png。historical_20261009是前版截圖及報告，不能當成本次病理數值。

23項守恆／解析極限檢查、24項真實JS事件的DOM檢查通過；12種部署流程模擬通過。完整瀏覽器未能啟動，沒有宣稱新的網站截圖或完整瀏覽器排版已驗證。比較圖是此教學模型的計算輸出，並非病人資料。

只需下載這份ZIP，使用給定PowerShell步驟呼叫其中DEPLOY_FROM_WINDOWS.ps1；不須再下載另一個小型PS1。server先核對本地服务，Windows核對tunnel，再發布完整清單並同步ORIGIN_URL，最後Windows核對公開HTML/JS及API。FULL DEPLOY VERIFIED才是公開部署核對完成。原後端、LLM、RAG與Worker邏輯未改；新部署入口處理的是完整資產更新與已驗證origin同步。

方法依據：https://publications.ersnet.org/content/erj/44/4/1023.full 與 https://publications.ersnet.org/content/erj/45/1/227 。文獻支持分流與血液含量混合原理，未驗證此模擬的所有參數與輸出。
