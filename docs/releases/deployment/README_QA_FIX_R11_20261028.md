# v241.12.5 完整版 R11：單題問答修正（2026-10-28）

以 R9（語音修正＋老師版 V/Q）為底，加上 R10 的課程名稱自動偵測，並修正「問一題就答不出來」。

## 單題答不出來的原因與修正

1. 回答前，系統要先把問題送到 BGE-M3 轉成向量，才能去課本找段落。伺服器的 GPU 被別人的訓練占滿、或上傳課程正在建索引時，這一步會等很久而逾時，結果整題沒有教材可用，就顯示「沒有足夠教材／檢索服務暫時無法使用」。
   - R11：BGE-M3 最多等 20 秒；逾時就改用課本原文的中英術語檢索找段落，照原本的流程回答，不再整題放棄。（R6 的做法，但 R6 只等 8 秒，伺服器一忙就幾乎每題都逾時。）
   - 問題分類（是否屬於生理學）加入吸氣、吐氣、呼氣、breath 等詞，避免一般問法被當成範圍外。
2. 雲端模型（GPT-5.6 Luna）單題回答的長度上限原本只有 650 tokens，中文說明一長就被截斷而整題作廢；三題一起問走另一條路、上限較大，所以反而成功。R11 把單題上限提高到 1,400。
3. 語音轉文字：KB 後端沒回應（HTTP 502–504）時，自動改走 /api/reference/stt。

## 上傳課程介面

維持原本的上傳課程模式（上傳 PDF → 確認章節 → 建立）。若伺服器裝過 R6，上架時會移除 R6 新增的「統一 AI 模式／圖像分析／本地或雲端」選項，回到原本介面；R6 後端「一次只準備一門課」仍保留，選取課程時會自動讓那門課繼續準備。

用回覆中的 LUNGTA_R11_DEPLOY.ps1。它會先在伺服器上實測一題教材檢索（修正前），再更新、重啟 Reference 後端、再測一次（修正後），並把結果印出來。伺服器上的程式版本若和預期不同，該部分會自動跳過，不會覆蓋。
