# 評測工具與資料

| 目錄 | 用途 |
|---|---|
| `three_model_10q/` | 目前三模型、10 題 pilot 的題目、來源與 runner |
| `five_model_benchmark/` | 既有五模型比較工具與題集模板 |
| `physician_benchmark/` | 既有醫師題目測試資料及摘要 |
| `vq_validation/` | 呼吸生理數值驗證與參考比較 |
| `validation_history/` | 歷史功能檢查輸出 |
| `legacy_benchmarks/` | 各版本國考及 seen regression 工具；須依當時設定解讀 |

指標、資料集用途與重現界線見[評測說明](../docs/evaluation.md)。實際模型測試需要另行準備服務、私有教材與必要金鑰。
