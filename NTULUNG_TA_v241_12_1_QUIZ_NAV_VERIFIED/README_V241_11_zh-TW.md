# v241.11：十題穩定出題、免驗證碼刪課、雲端直接回答

## 變更與實際機制

1. **題庫在建課程期間完成。**每單元從可讀 PDF 句子挑選來源知識點，組成 100 道完整的四選一教材證據判讀題。題幹設置臨床實習或案例討論，要求選出與指定概念及關係直接相關的教材敘述；四個選項都取自同單元的不同原句，正解與解析可對回原文。這個穩定的規則式題型不捏造治療效果；深度臨床決策題仍需要另外的專家審題與生成流程。若某單元沒有足夠可讀內容，準備狀態會明確顯示不足，不會在學生按 Start 時才隨機報錯。
2. **Start Quiz 不再寫題。**選每單元 1–10 題後，後端直接從保存的 100 題抽取，優先避免同一次測驗重複同一原句，建立測驗紀錄並立即傳回題目；此步驟模型呼叫數為 0。交卷與累計統計仍保存。舊版 v241.10 的課程會在服務啟動時用已保存的 PDF 文字重建完整題庫，無須重新上傳。
3. **刪課不再需要驗證碼。**在課程選單選擇上傳課程，按 Delete selected course，確認刪除內容即可。刪除只針對該門上傳課程；內建課程不可刪。伺服器保留刪除紀錄，以免後續版本搬移舊資料時讓已刪課程重新出現。此版本沒有使用者登入，因此能操作公開網站 API 的人也能請求刪課；若未來要限制管理者，需要另加帳號權限。
4. **確認雲端 API Key 後，問答直接用雲端。**依然先檢索所選教材、檢查範圍；有足夠教材時立即呼叫已選雲端模型，不先等本機 10 秒。Off — Local only 仍用本機。批次及單題都走此分流；雲端金鑰或服務錯誤會顯示錯誤，不會悄悄換成本機答案。先前已驗證保存的同課程同題修正答案可直接使用。

## 最快部署

下載本 ZIP 後，在 Windows PowerShell 執行：

```powershell
scp "$env:USERPROFILE\Downloads\NTULUNG_TA_v241_11_INSTANT_QUIZ_DIRECT_CLOUD.zip" USER@YOUR_SERVER:/path/to/workdir/
ssh USER@YOUR_SERVER "cd /path/to/workdir && unzip -o NTULUNG_TA_v241_11_INSTANT_QUIZ_DIRECT_CLOUD.zip && cd NTULUNG_TA_v241_11_INSTANT_QUIZ_DIRECT_CLOUD && chmod +x *.sh && ./INSTALL_FINAL.sh"
```

完成後在瀏覽器重新整理 `https://lungta.twchu.workers.dev/reference/`。健康檢查版本應為 `v241.11-instant-quiz-direct-cloud`。安裝器會保留 v241.10 的課程工作區、測驗統計、回報與郵件設定。舊課程的完整題庫需於啟動後準備；頁面顯示 100/100 才可開始測驗。

## 驗證

`./CHECK_V241_2_ONE_CLICK_STABLE.sh` 包含生成 PDF 的整條上傳／建課流程、兩單元各 100 題、每單元 1 與 10 題的抽題／交卷、舊 v241.10 課程升級、刪課、回報，以及 Worker 的模擬雲端 API 路由。另一個 28 單元 × 每單元 10 題的合成資料抽題測試，於本機完成 280 題抽取約 0.02 秒、0 次模型呼叫。這是**抽題**時間，沒有涵蓋真實 PDF 上傳、題庫準備、網路、真實雲端 API 或教材題目品質；部署後仍需以實際藥理學 PDF 和真實模型檢查。
