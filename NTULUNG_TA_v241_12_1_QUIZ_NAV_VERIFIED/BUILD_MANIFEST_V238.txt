Purpose
- Preserve the v237 accuracy-first physiology/RAG decision improvements.

Changes

4. Reference async batch wrapper contains an independent fallback parser so one parser failure cannot silently collapse a multi-question batch to a single question.
5. Batch wrappers install idempotently to avoid repeated nested wrappers from delayed installation timers.
6. Every batch response remains formatted with an explicit 第 N 題 / Question N heading.
7. Existing server-side missing-item recovery remains active.
8. Production physiology scope, 4,792-passage corpus, 16,151 rerank windows, v237 accuracy-first selective verification, BYOK cloud path, scope lock, TTS/STT/avatar/Hopkins behavior are preserved.
