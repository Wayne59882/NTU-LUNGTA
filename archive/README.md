# 歷史工具與前端實作

這裡保留目錄重整前的部署工具、版本安裝鏈與未載入的前端腳本，用於追溯舊版行為。

| 目錄 | 內容 |
|---|---|
| `deployment/` | 舊版完整 ZIP、PowerShell 與 Worker 更新工具 |
| `application_tools/` | 各版本安裝、檢查及舊語音工具 |
| `frontend/` | 目前頁面沒有載入的歷史 JavaScript 與 CSS |

這些工具的原始相對路徑對應舊版封裝，未改寫成目前的執行入口。正式程式見 [app](../app/)，目前操作方式見[安裝文件](../docs/getting-started.md)。如需重現當時封裝，使用重整前的 commit `16701b93f1d24dfd6798a690689c1a5e5b942f2f`。
